# The blanket "User-agent: * / Allow: /" above already permits every one of
# these, so the named blocks below are documentation rather than mechanism.
# They exist so that nobody "tidies up" this file later by adding a Disallow
# and quietly cuts off a channel that already produced a real lead: a
# prequalification arrived 2026-08-20 with utm_source=chatgpt.com.
#
# The three groups do genuinely different things and we want all three:
#
#   TRAINING      — pages enter model training corpora. Slow, unattributable,
#                   but it is how you become the default answer to
#                   "mortgage broker Melbourne FL" with no fetch at all.
#   RETRIEVAL     — builds the live index an assistant queries while answering.
#                   Blocking one of these removes you from answers today.
#   USER-TRIGGERED— fetches this page right now because a human asked the
#                   assistant about us by name. Never block these; it is
#                   blocking a prospect mid-question.
# ---------------------------------------------------------------------------
