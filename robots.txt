# ---------------------------------------------------------------------------
# Homesite Mortgage - robots.txt
#
# READ THIS BEFORE EDITING. A crawler obeys exactly ONE group: the most specific
# one whose token matches it (RFC 9309 s2.2.1). It does NOT fall through to
# `User-agent: *` afterwards. Giving a crawler its own group therefore EXEMPTS it
# from every rule in the `*` group. That is how nineteen near-duplicate city
# pages stayed open to every AI crawler for weeks while appearing blocked.
#
# Those nineteen pages have since been deleted rather than hidden, so the
# Disallow block that used to live here is gone with them. If a rule ever needs
# to apply to a named crawler again, it has to be repeated inside that crawler's
# own group - multiple User-agent lines may share one group, which is why the
# tokens below are stacked rather than repeated.
# ---------------------------------------------------------------------------

User-agent: *
Allow: /

# ---------------------------------------------------------------------------
# AI crawlers - all explicitly welcomed.
#
# The blanket Allow above already permits every one of these, so these groups
# are documentation rather than mechanism. They exist so nobody "tidies up" this
# file later by adding a Disallow and quietly cuts off a channel that already
# produced a real lead: a prequalification arrived 2026-08-20 with
# utm_source=chatgpt.com.
#
# The three tiers do genuinely different things and we want all three:
#   TRAINING       - pages enter model training corpora. Slow, unattributable,
#                    but it is how you become the default answer with no fetch.
#   RETRIEVAL      - builds the live index an assistant queries while answering.
#                    Blocking one of these removes you from answers today.
#   USER-TRIGGERED - fetches this page right now because a human asked the
#                    assistant about us by name. Never block these.
#
# Google-Extended and Applebot-Extended are robots.txt control tokens, not
# crawlers. They govern whether already-crawled content may be used for Gemini /
# Apple Intelligence grounding and training. Opt-out only, so allowing them is
# what keeps us eligible.
# ---------------------------------------------------------------------------
