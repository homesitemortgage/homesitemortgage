# Content Engine — Topic Backlog

The nightly engine works **top-down**: it picks the first unchecked `[ ]` item,
produces the page, and checks it off `[x]` in the same PR. One page per run.

Slugs follow `first-time-home-buyer-<area>-fl.html`. Each entry lists the
primary local keyword and the cities/areas to mention (the engine must
**verify** these are actually in the named county before using them — see
`ENGINE.md` step 3).

Priority order is roughly by market size and likely lead value. Reorder freely.
